## Suggested Reading Order

1. Start with [Getting Started](getting-started.md).
2. Continue with [Loading Models](loading-models.md).
3. Use [Typed Entity Access](typed-entities.md) when you need object-level IFC data.
4. Use [Walking The Model](walking-the-model.md) to reach data that isn't on the nodes: types, classifications, systems, openings, entities without geometry.
5. Keep [API Reference](api-reference.md) open while scripting.
6. Use [Building From Source](building-from-source.md) for local development and custom binaries.
